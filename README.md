# Angular Premier League FM

Proyecto **Fantasy Manager de la Premier League** desarrollado con **Angular 19** como parte de un proyecto académico.

---

## 🛠️ Tecnologías
- Angular 19
- TypeScript
- Standalone Components
- Angular Router
- Zoneless Change Detection

---

## 🚀 Development server

Para levantar el servidor de desarrollo en local:

```bash
ng serve
``
